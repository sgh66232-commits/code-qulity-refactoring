Code Quality & Refactoring

معرفی پروژه

این پروژه با هدف بررسی مفهوم کیفیت کد (Code Quality) و بازآرایی کد (Refactoring) در درس توسعه نرم‌افزار تهیه شده است.

در این پروژه، با استفاده از زبان برنامه‌نویسی Python یک برنامه ساده محاسبه قیمت با تخفیف پیاده‌سازی شده است.

اهداف پروژه

- آشنایی با مفهوم کیفیت کد
- شناخت اهمیت خوانایی و نظم در برنامه‌نویسی
- آشنایی با مفهوم Refactoring
- بهبود ساختار کد بدون تغییر در عملکرد برنامه
- آشنایی عملی با Git و GitHub

ابزارهای استفاده‌شده

- Python
- Visual Studio Code
- Git
- GitHub

بخش‌های پروژه

- پیاده‌سازی برنامه اولیه
- بررسی ساختار و کیفیت کد
- آشنایی با روش‌های بهبود کد
- مدیریت نسخه‌های پروژه با Git
- بارگذاری پروژه در GitHub

نتیجه‌گیری

کیفیت کد و بازآرایی آن باعث افزایش خوانایی، نگهداری آسان‌تر و توسعه بهتر نرم‌افزار می‌شوند. همچنین استفاده از Git و GitHub امکان ثبت و مدیریت تغییرات پروژه را فراهم می‌کند.
